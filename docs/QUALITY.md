# Quality

このリポジトリでは、教材内容だけでなく、問題データ・学習状態・公開サイト導線・第三者が再現できるリポジトリ構成を品質対象にしています。

## 自動検証

```bash
node scripts/build-sites.mjs
node --test quiz/test_quiz.mjs quiz/test_backup.mjs scripts/test-sites.mjs scripts/test-public-ux.mjs
```

同じ検証はGitHub Actionsでも実行します。

## 主な検証対象

| 領域 | 検証内容 |
| --- | --- |
| 問題 | 105問、ID、正答、選択肢、分野、65問模試の比率 |
| 学習状態 | 回答履歴、弱点、バックアップ、復元 |
| 教材 | 01〜09とreferencesの公開順、旧個人教材の混入防止 |
| 公開UX | 公開サイトから教材・全問題・模試・弱点へ到達できること |
| Build | 静的クライアント、問題資産、最小Workerが生成されること |
| プライバシー | 固定試験日・個人模試結果・個人学習データを公開物へ含めないこと |
| 再現性 | 個人PCの絶対パスやcredentialへ依存しないこと |

## 手動確認

関連変更時には次も確認します。

- AWS公式資料と教材説明に矛盾がないこと
- 正答だけでなく、他の選択肢を外す理由が妥当なこと
- デスクトップとスマホ幅で主要導線が使えること
- 外部図解の参照先・ライセンス・説明が適切なこと
- 公開サイトのファーストビューから学習開始まで迷わないこと

## 公開品質の受入基準

- READMEから公開サイト、目的、技術構成、ローカル利用、検証、ライセンスへ到達できる。
- Node.js 22以上だけでbuild・testできる。
- 個人端末の絶対パス、秘密情報、個人模試履歴を公開資料へ残さない。
- 非公式教材であることとAWS公式資料を優先する方針を明記する。
