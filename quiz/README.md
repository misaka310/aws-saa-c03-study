# SAA-C03 問題演習

SAA-C03向けの105問を使って、分野別練習・復習・65問模試を行えます。

## 使えるモード

- **65問模試** — 4分野をまたいで本番形式で解く
- **全105問** — 標準問題を一通り解く
- **新着問題** — 最近追加された問題を確認する
- **未回答だけ** — まだ解いていない問題を進める
- **間違いだけ** — 直近で間違えた問題を解き直す
- **弱点補強** — 回答履歴から苦手な論点に関連する問題を解く
- **分野別練習** — Secure / Resilient / Performance / Costを選んで解く

## 問題の見方

回答を送信すると、正解だけでなく各選択肢の理由を確認できます。

復習では次の3点を説明できるか確認してください。

1. 問題文のどの条件が決め手だったか。
2. なぜ正解のサービスが要件を満たすのか。
3. 最も迷った別の選択肢をなぜ外せるのか。

## 解き直し

過去に解いた問題でも、開いただけでは前回の答えや正解を表示しません。今回の回答を送信した後に採点と解説を表示します。

「間違いだけ」で解き直したあとも、過去に苦手だった論点は弱点分析に利用されます。

## 弱点補強

問題を解くと、苦手な論点をまとめて確認できます。同じ問題だけを暗記するのではなく、関連する別問題へ広げて復習するために使います。

## 学習結果の移動

学習結果はJSONで書き出し・復元できます。別の端末へ移るときや、ブラウザのデータを消す前のバックアップに利用してください。

## おすすめの流れ

1. [01 はじめに](../01-start-here.md) で全体の進め方を確認する。
2. [02 サービス選択](../02-service-selection.md) と4分野の教材を読む。
3. 全105問または分野別練習を解く。
4. 間違いだけ・弱点補強で復習する。
5. 65問模試で分野をまたいだ判断を確認する。
6. [08 最終確認](../08-final-review.md) で仕上げる。

問題の内容やAWS仕様に疑問がある場合は [References](../references.md) のAWS公式資料を優先してください。
